## 한국어

**Tailscale IP 찾기**
- Windows·macOS에 Tailscale을 직접 설치한 경우에도 찾을 수 있게: 이 서버의 Tailscale 기기 이름을 넣으면 Tailscale DNS(MagicDNS)에 물어 주소를 찾습니다
- Windows 설치 스크립트(`install.ps1`)가 호스트의 `tailscale ip -4`를 읽어 `GM_TAILSCALE_IP`로 넘깁니다

**설정 마법사**
- Cloudflare 단계에서 토큰을 붙여넣고 저장 버튼 없이 「다음」을 누르면 토큰이 버려지던 문제 — 이제 「다음」이 검증 후 저장합니다
- 설치 중인데도 「길목이 설치한 …에 연결되어 있습니다」가 나오던 문제 — 작업 중 / 연결됨 / 컨테이너 없음을 실제 상태로 표시
- 설치 진행 표시(경과 시간·마지막 출력), 설치 버튼 상태, 설치 후 연결 정보가 덮어써지던 문제
- Caddyfile·Authelia 경로 칸의 「찾아보기…」, 가져오기의 「PC에서 Caddyfile 고르기…」

**CrowdSec**
- 길목을 초기화한 뒤 다시 설치하면 LAPI가 「바운서 키를 거부」하던 문제 — 설치·시작 때 바운서 `gilmok`을 길목의 현재 키로 다시 등록합니다. 점검 결과에 「바운서 키 다시 등록」 버튼

## English

**Finding the Tailscale IP**
- Works when Tailscale is installed directly on Windows / macOS: enter this server's Tailscale device name and Gilmok asks the Tailscale DNS (MagicDNS) for its address
- The Windows installer (`install.ps1`) reads the host's `tailscale ip -4` and passes it as `GM_TAILSCALE_IP`

**Setup wizard**
- A token pasted in the Cloudflare step was dropped when you pressed "Next" without its save button — "Next" now verifies and saves it
- "Connected to the … Gilmok installed" showed while the install was still running — the real state is shown now (in progress / connected / container missing)
- Install progress (elapsed time, last output), the install button state, and connection settings being overwritten after an install
- "Browse…" for the Caddyfile / Authelia paths, and "Choose a Caddyfile on this PC…" for import

**CrowdSec**
- After resetting Gilmok and reinstalling, the LAPI rejected the bouncer key — the bouncer `gilmok` is registered again with Gilmok's current key on install and start. A "Register the bouncer key again" button in the check results
