요청마다 접속자 IP·국가를 기록하고, Cloudflare를 거치지 않는 사이트를 Caddy에서 국가로 막을 수 있게 한 릴리스입니다. · Records the client IP and country of every request, and adds a country block in Caddy for sites that do not go through Cloudflare.

```bash
docker pull vitive/gilmok:0.1.12   # linux/amd64 · linux/arm64
```

**업데이트 · Upgrading:** `docker compose pull && docker compose up -d`

## 한국어

- 접속자 정보: 요청마다 접속자 IP·국가·경로(Cloudflare / 직접 / 내부망 / Tailscale)를 기록 — 로그 탭 목록·CSV(`country`, `client_via` 열), 요청 상세, 응답시간 분포 점에 표시. 대시보드 위젯 「접속자 IP」·「접속 국가」 추가
  - Proxied 사이트: Cloudflare가 넘겨 준 실제 접속자 IP·국가
  - 그 밖의 사이트: Caddy가 본 IP + 국가 DB로 판정
  - Docker Desktop이 바꾼 내부 주소는 가짜 주소 대신 「알 수 없음」
- 국가 DB: 길목이 시작할 때와 한 달에 한 번 [DB-IP](https://db-ip.com) IP to Country Lite(CC BY 4.0, 약 8MB, 키 없음)를 자동으로 받습니다. Caddy 탭 › 보호 › 국가 차단에서 끌 수 있습니다. IP Geolocation by DB-IP
- 국가 차단 (Caddy 탭 › 보호 › 국가 차단): 「허용 국가만 들어옴」 또는 「지정 국가 차단」, 적용할 사이트 선택. 막힌 요청은 403, 차단 기록에 「국가 차단」. 내부망·Tailscale 주소는 막지 않습니다. Proxied 사이트는 Cloudflare 탭의 국가 규칙으로 막습니다
  - Caddy에 GeoIP 모듈(`caddy-maxmind-geolocation`)이 필요합니다. **길목이 설치한 Caddy는 Caddy 탭 › 이미지 업데이트로 한 번 다시 빌드하세요**(Dockerfile은 자동으로 바뀝니다). 직접 운영하는 Caddy는 xcaddy build에 `--with github.com/porech/caddy-maxmind-geolocation`을 추가하세요. 준비되기 전에는 국가 차단만 빼고 적용하고 이유를 적용 미리보기에 보여 줍니다
  - Docker Desktop(Windows·macOS)에서는 Caddy가 실제 접속자 주소를 보지 못해 아무것도 막지 않습니다(화면에 경고)

## English

- Client details: every request records the client IP, country and path (Cloudflare / direct / LAN / Tailscale) — in the Logs tab list and CSV (`country`, `client_via` columns), the request details and the response-time dots. New dashboard widgets "Client IPs" and "Client countries"
  - Proxied sites: the real client IP and country passed on by Cloudflare
  - Other sites: the IP Caddy saw + the country database
  - A Docker-internal address rewritten by Docker Desktop shows as "unknown" instead of a fake address
- Country database: Gilmok downloads [DB-IP](https://db-ip.com) IP to Country Lite (CC BY 4.0, about 8 MB, no key) at start and once a month. It can be turned off in Caddy tab › Protection › Country block. IP Geolocation by DB-IP
- Country block (Caddy tab › Protection › Country block): "only listed countries" or "block listed countries", per-site scope. Blocked requests get 403 and show as country blocks in the block log. LAN and Tailscale addresses are never blocked. Proxied sites are blocked by the Cloudflare tab's country rule instead
  - Caddy needs the GeoIP module (`caddy-maxmind-geolocation`). **For a Caddy installed by Gilmok, rebuild it once with Caddy tab › Image update** (its Dockerfile is updated automatically). For your own Caddy, add `--with github.com/porech/caddy-maxmind-geolocation` to the xcaddy build. Until it is ready, the country block is left out of the apply and the reason is shown in the preview
  - On Docker Desktop (Windows, macOS) Caddy cannot see real client addresses, so it blocks nothing (the screen warns about this)
