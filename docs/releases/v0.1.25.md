## 한국어

- 로그아웃하거나 세션이 만료된 뒤 로그인 창에 비밀번호를 입력하는 도중 몇 초마다 지워지던 문제 — 화면 뒤의 자동 새로고침(대시보드 등)이 「로그인 필요」를 받을 때마다 로그인 창을 다시 그렸습니다. 이제 이미 떠 있는 로그인 창은 그대로 두고, 로그인 창이 뜨면 대시보드 새로고침을 멈춥니다

## English

- After logging out (or when a session expired), the password field was cleared every few seconds while typing — background refreshes such as the dashboard redrew the login form on every "login required" answer. A login form already on screen is now left alone, and the dashboard stops refreshing while it is shown
