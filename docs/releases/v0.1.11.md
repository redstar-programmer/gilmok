대시보드 「서비스 상태」 위젯을 단순하게 바꾸고, 응답시간 분포의 상태코드를 토글 버튼으로 바로 켜고 끄게 한 릴리스입니다. · Simplifies the dashboard's service status widget and turns the status classes of the response-time chart into toggle buttons.

```bash
docker pull vitive/gilmok:0.1.11   # linux/amd64 · linux/arm64
```

**업데이트 · Upgrading:** `docker compose pull && docker compose up -d`

## 한국어

- 서비스 상태 위젯: 확인 기록 막대와 설명 문장을 빼고, 서비스마다 색 점 하나 — 파랑 서비스 중 · 노랑 느림(500ms 이상) · 빨강 응답 없음. 위에는 상태별 개수만 한 줄로. Caddy가 멈췄을 때의 「Caddy 중단」 표시는 그대로
- 응답시간 분포·상태코드별 추이: 2xx·3xx·4xx·5xx가 토글 버튼 — 누르면 그래프에서 바로 보이기·감추기(꺼진 것은 점선 테두리), 브라우저에 기억

## English

- Service status widget: no history bars or explanation; one colored dot per service — blue serving · yellow slow (500 ms or more) · red no response — and one line of counts per state above. The "Caddy down" notice stays
- Response-time distribution and requests by status: 2xx · 3xx · 4xx · 5xx are toggle buttons — click to show or hide a class on the chart right away (off = dashed outline), remembered per browser
