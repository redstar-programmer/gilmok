구성도를 다루기 쉽게 다듬은 릴리스입니다 — 끌어서 이동, 흐름 애니메이션 기본 켜기, Cloudflare 한 칸. · Easier topology — drag to move, flow animation on by default, one Cloudflare box.

```bash
docker pull vitive/gilmok:0.1.20   # linux/amd64 · linux/arm64
```

**업데이트 · Upgrading:** `docker compose pull && docker compose up -d`

## 한국어

- 구성도를 마우스로 끌어 이동 (확대했을 때 좌우는 구성도 안에서, 위아래는 페이지가 함께). 칸 위에서 시작해도 되고, 끈 뒤에는 칸 편집 창이 열리지 않습니다 — 그냥 클릭은 그대로 편집
- 「흐름」 기본값을 「켜기」로 — 원격 데스크톱처럼 「동작 줄이기」 컴퓨터에서도 처음부터 흐릅니다. 운영체제 설정을 따르려면 「자동」
- Cloudflare를 한 칸으로: 길목의 API 호출(DNS·WAF 규칙·차단 목록)이 공유기를 거쳐 같은 Cloudflare 칸 아래로 들어갑니다 (CrowdSec 차단 목록은 위로). Proxied 사이트가 없을 때만 「Cloudflare API」 칸을 따로 둠
- 라벨 겹침 정리

## English

- Drag the topology to move around (when zoomed: sideways inside the map, up and down on the page). Dragging can start on a box; a drag never opens the box's editor — a plain click still does
- "Flow" now defaults to "On", so the lines move even with "reduce motion" (e.g. remote desktop). "Auto" follows the OS setting
- One Cloudflare box: Gilmok's API calls (DNS, WAF rules, block list) go out through the router into the bottom of the same Cloudflare box (the CrowdSec block list into its top). A separate "Cloudflare API" box only when no site is Proxied
- Overlapping labels moved apart
