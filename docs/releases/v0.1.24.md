## 한국어

- **신뢰할 수 있는 기기**: 2단계 인증 코드를 입력할 때 「이 기기 신뢰」를 고르면, 그 브라우저에서는 정한 기간(기본 30일, 7~90일) 동안 **비밀번호만으로** 로그인합니다. 비밀번호는 매번 묻습니다
  - 설정 › 내 계정 › 신뢰하는 기기: 목록(브라우저·IP·마지막 사용·만료, 「이 브라우저」 표시), 하나씩·모두 해제
  - 비밀번호를 바꾸거나 2단계 인증을 다시 등록·초기화하면 그 계정의 신뢰 기기는 모두 풀립니다
  - 설정 › 접근 보안: 신뢰 기기 끄기 · 유지 기간. 계정 관리에서 다른 계정의 신뢰 기기 해제
  - 서버에는 쿠키의 해시만 저장, 쿠키는 HttpOnly · SameSite=Strict, 계정마다 따로
- **재시작해도 로그인 유지**: 길목을 재시작·업데이트해도 다시 로그인할 필요가 없습니다 (유휴·최대 시간 제한은 그대로). 세션 파일에도 해시만 저장되고, 로그아웃은 바로 기록됩니다

## English

- **Trusted devices**: choose "Trust this device" when entering the two-step code, and that browser signs in **with the password only** for the chosen period (30 days by default, 7–90). The password is always asked
  - Settings › My account › Trusted devices: the list (browser, IP, last used, expiry, "this browser"), revoke one or all
  - Changing the password, or re-enrolling / resetting two-step verification, revokes every trusted device of the account
  - Settings › Access security: turn trusted devices off, set the period. Account managers can revoke someone's devices
  - Only a hash of the cookie is stored; the cookie is HttpOnly and SameSite=Strict, one per account
- **Stay logged in across restarts**: restarting or updating Gilmok no longer logs everyone out (idle and maximum session limits still apply). The session file holds hashes only, and a logout is written at once
