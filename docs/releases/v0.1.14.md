## 한국어

- 실시간 기간: 「위젯 설정대로」를 없애고 모든 위젯이 같은 기간을 봅니다 — 1·5·10·15·30분, 1·2·3시간, **기본 15분**. 위젯 제목 옆에 「최근 15분」처럼 정확한 기간 표시. 위젯 편집의 「기간」 칸은 없어짐
- 위젯 추가: 미리 만든 위젯 23종을 미리보기 카드(작은 그림 + 설명 + 폭)로 보여 주고, 여러 개를 골라 「선택한 N개 추가」. 대시보드에 이미 있는 것은 「이미 있음」 표시, 쓰지 않는 구성요소의 위젯은 숨김. 세부 설정은 「직접 구성…」
- 위젯 편집(✎): 종류 목록 없이 그 위젯에 필요한 칸만
- 끌어서 옮기기: 끄는 동안 다른 위젯이 바로 자리를 비켜 주고(애니메이션), 놓을 때 한 번 저장. 저장에 실패하면 원래 배치로

## English

- Live period: no more "per widget" — every widget shows the same period: 1 · 5 · 10 · 15 · 30 minutes, 1 · 2 · 3 hours, **15 minutes by default**. Each widget header shows the exact period ("Last 15 minutes"); the period field is gone from the widget editor
- Add widget: 23 ready-made widgets as preview cards (small drawing, description, width); pick several and "Add N selected". Widgets already on the dashboard are marked, widgets for unused components are hidden; "Build your own…" opens the detailed editor
- Edit widget (✎): only the fields that widget needs, no type list
- Drag to reorder: the other widgets slide out of the way while dragging (animated); saved once on drop, and put back if saving fails
