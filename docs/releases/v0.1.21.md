## 한국어

- **배치**: 24칸 격자 — 제목 줄을 끌어 옮기고 오른쪽 아래 모서리로 크기 조절, 다른 패널은 바로 비켜남 (Alt+화살표 이동, Alt+Shift+화살표 크기). 예전 배치는 처음 열 때 한 번 바뀌어 저장
- **패널 메뉴 ⋮**: 크게 보기, 데이터 보기(표 + CSV), 편집, 복제, 삭제
- **시간**: 최근 5분 ~ 30일 또는 시작·끝 직접 지정(최대 31일), ◀ ▶ 로 옮기기, ⊖ 로 넓히기, 추이 차트를 끌어서 그 구간 확대, 차트끼리 같은 시각에 세로선
- **필터**: 사이트 · 상태 · 국가 · 접속 경로 — 숫자·추이·분포·순위·지도 패널과 요청 목록에 함께 적용. 순위 행을 누르면 그 값으로 필터
- **응답시간 분포 (X-View 방식)**: 상태별 건수, 요약(건수·평균·최대·5xx), 세로축 최대값(자동·1~30초, Shift+휠), 넘는 요청은 위쪽 ▲, 500ms 「느림」 선, p50·p95 선. 박스로 고르면 요청 목록(요약·열 정렬)
- **서비스 상태**: 타일 / 원형 / 막대. 원형은 전체 묶음(고리 하나) 또는 서비스별(최근 점검 기록·가용률)
- **컨테이너 리소스**: 목록 / 게이지(원형) / 막대, 멈춘 컨테이너는 한 줄로
- 패널별 크기(자동·작게·보통·크게)와 색 지정

## English

- **Layout**: a 24-column grid — drag a title bar to move a panel, its bottom-right corner to resize; the others move out of the way live (Alt+arrows move, Alt+Shift+arrows resize). An older layout is converted once when first opened
- **Panel menu ⋮**: view, inspect data (table + CSV), edit, duplicate, delete
- **Time**: last 5 minutes to 30 days, or an absolute from/to (up to 31 days); ◀ ▶ to shift, ⊖ to zoom out, drag across a trend chart to zoom into it; a shared crosshair across the charts
- **Filters**: sites · status · countries · client path — applied to the number, trend, scatter, ranking and map panels and to the request list. Clicking a ranking row filters by it
- **Response-time scatter (X-View style)**: counts per status, a summary (count, avg, max, 5xx), a vertical scale (auto, 1–30 s, Shift+wheel) with ▲ for requests above it, a 500 ms "slow" line, p50 / p95 lines. Drag a box for the request list (summary, sortable columns)
- **Service status**: tiles / ring / bars. The ring shows everything together or one ring per service (recent checks, availability)
- **Container resources**: list / gauges / bars; stopped containers on one line
- Per-panel size (auto, small, medium, large) and colors
