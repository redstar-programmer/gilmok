대시보드에서 길목이 설치한 구성요소를 바로 살리고, 대시보드 기간 선택·과거 From~To, Caddy가 멈췄을 때의 서비스 상태, 구성도 상태·확대·가리기를 더한 릴리스입니다. · Bring managed components back from the dashboard; dashboard ranges and a past From~To window; service status that knows when Caddy is down; status, zoom and blind mode on the topology map.

```bash
docker pull vitive/gilmok:0.1.8   # linux/amd64 · linux/arm64
```

**업데이트 · Upgrading:** `docker compose pull && docker compose up -d`

## 한국어

- **대시보드 「길목이 설치한 구성요소」**: 길목이 설치한 Caddy·Authelia·CrowdSec마다 상태·실행 시간·재시작 횟수·헬스체크, 멈췄거나 재시작을 반복하면 로그에서 찾은 원인 한 줄. 상태에 맞는 버튼 — 시작 / 다시 시작 / 다시 설치(남아 있는 설정·데이터로) / 진행 보기, 그리고 로그(최근 300줄)·관리. 길목이 설치한 것이 없으면 나오지 않습니다
- **구성도**
  - Caddy·Authelia·CrowdSec 칸에 컨테이너 상태 점, 내려가면 빨간 점선 테두리
  - 확대·축소(60%~200%, 맞춤), 브라우저에 기억
  - 「주요 정보 가리기」: 공인·사설 IP, IPv6, 도메인, 대상 호스트, 호스트 이름을 가립니다(스크린샷 공유용, 데이터는 그대로)
- **대시보드 기간**: 실시간은 「위젯 설정대로 / 최근 1분·5분·10분·30분·1시간·2시간·3시간」으로 모든 위젯을 한 번에, 과거 보기는 시작 ~ 끝(최대 1일)으로 조회
- **Caddy가 멈추면 서비스 상태가 「Caddy 중단」**: 서비스 상태는 길목이 대상에 직접 연결해 판정하므로 Caddy가 꺼져도 「정상」으로 보였습니다. 이제 Caddy 컨테이너(또는 관리 API) 상태도 함께 보고 목록·구성도·대시보드에 접속 불가로 표시합니다(대상 응답 여부는 툴팁). 서비스 상태가 바뀌어도 화면이 다시 그려지지 않던 문제도 고침
- 상단 이름 옆에 버전 표시
- API: `GET /api/stacks/{name}/logs`, `POST /api/dash/data`의 `range`·`from`/`to`, `GET /api/health`의 `caddy`
- 개발: 화면 스크립트의 전역 이름 중복을 잡는 테스트

## English

- **Dashboard "Components installed by Gilmok"**: state, uptime, restart count and health of each managed Caddy / Authelia / CrowdSec, plus the reason line from the log when it stopped or crash-loops. Buttons by state — start / restart / reinstall (with the settings and data left in place) / show progress, plus logs (last 300 lines) and manage. Hidden when Gilmok installed nothing
- **Topology map**
  - Container status dot on the Caddy, Authelia and CrowdSec boxes; a red dashed border when one is down
  - Zoom (60%–200%, fit), remembered per browser
  - "Hide key details": masks public / private IPs, IPv6, the domain, upstream hosts and the host name (for sharing screenshots; the data is unchanged)
- **Dashboard ranges**: the live view shows every widget over "per widget / last 1, 5, 10, 30 minutes, 1, 2, 3 hours"; the past view takes a start ~ end window (at most one day)
- **Service status says "Caddy down" when Caddy is stopped**: status is probed from Gilmok straight to each upstream, so it stayed "OK" with Caddy off. It now also checks the Caddy container (or admin API) and marks the sites unreachable in the list, the map and the dashboard (the upstream result stays in the tooltip). Also fixes the list / map not redrawing when a service's state changed
- Version next to the name in the top bar
- API: `GET /api/stacks/{name}/logs`, `range` and `from`/`to` on `POST /api/dash/data`, `caddy` in `GET /api/health`
- Development: a test that catches a top-level name declared in two UI scripts
