대시보드에 접속 지역 세계지도를 넣고, 접속자를 「IP | 국가」 한 줄로 보여 주며, 접속자를 알 수 없는 이유를 이 서버 환경에 맞게 설명하는 릴리스입니다. · Adds a world map of client locations to the dashboard, shows clients as "IP | country", and explains — for this server's setup — why some clients are unknown.

## 한국어

- 대시보드 위젯 「접속 지역 (세계지도)」: 나라별 요청을 원 크기로, 거부(403·429)는 빨간 원. 「전체 요청 / 거부만」 전환, 원에 마우스를 올리면 요청·접속자 IP 수·비율·상태코드별 개수·많이 들어온 사이트. 실시간·과거 보기 모두. 새 설치의 기본 배치에 들어 있고, 이미 쓰던 대시보드는 「위젯 편집 → 위젯 추가」로 넣으세요
- 접속자 표시: 로그·요청 상세·분포 점에서 `211.222.111.111 | 중국`처럼 한 줄로. 내부 주소는 「Tailscale」·「내부망」
- Cloudflare가 국가 헤더(CF-IPCountry)를 보내지 않는 존에서도 Proxied 요청의 국가를 길목의 국가 DB로 찾습니다
- 「접속자를 알 수 없는 요청 — 왜 그런가요?」: 길목이 Docker 환경(Docker Desktop, rootless, Swarm, 리눅스 bridge의 IPv6 여부, host 네트워크, Docker 밖)을 감지해 그 서버의 원인과 해결 방법만 보여 줍니다. Caddy 탭 › 국가 차단의 경고도 같은 기준(아무것도 못 막음 / IPv6만 못 막음)
- 응답시간 분포·상태코드별 추이의 2xx·3xx·4xx·5xx에 마우스를 올리면 뜻과 대표 코드 설명. 말풍선이 위젯·화면 가장자리에서 잘리지 않음
- 처음 설정이 끝나기 전에는 상단 바에 「설정 마법사」 버튼 — 마법사를 닫은 뒤에도 바로 다시 열 수 있음
- 도메인을 아직 정하지 않았으면 서비스 추가·편집 창에서 바로 입력
- 구성도: 조작 버튼(묶기·확대·가리기)과 현황 숫자를 나눠 현황이 버튼처럼 보이지 않게
- 세계지도 육지 윤곽: Natural Earth(퍼블릭 도메인), world-atlas(ISC)에서 변환해 내장 — 실행 중 외부에서 받지 않음

## English

- Dashboard widget "Client locations (world map)": circles sized by requests per country, refused requests (403 · 429) in red. Toggle "All requests / Refused only"; hovering a circle shows requests, client IPs, share, status classes and the most visited sites. Live and past views. Part of the default layout for new installs — on an existing dashboard add it with "Edit widgets → Add widget"
- Clients shown on one line as `211.222.111.111 | China` in the logs, request details and response-time dots; internal addresses as "Tailscale" / "LAN"
- Proxied requests get a country from Gilmok's country database when the zone sends no CF-IPCountry header
- "Requests with an unknown client — why?": Gilmok detects the Docker setup (Docker Desktop, rootless, Swarm, Linux bridge with or without IPv6, host network, outside Docker) and shows only the cause and fixes for this server. The country block warning in the Caddy tab uses the same check (blocks nothing / cannot block IPv6)
- Hovering 2xx · 3xx · 4xx · 5xx on the response-time charts explains each class with typical codes; popovers no longer get cut off at widget or screen edges
- Until the initial setup is finished, a "Setup wizard" button sits in the top bar, so the wizard is one click away after closing it
- With no domain set yet, the service editor asks for it directly
- Topology: the view controls (group, zoom, hide) are separated from the read-only counts so the counts no longer look like buttons
- World map land outline: Natural Earth (public domain) converted from world-atlas (ISC), built in — nothing is downloaded at run time
