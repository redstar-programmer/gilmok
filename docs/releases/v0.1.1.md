## 한국어

Caddy + Authelia + Cloudflare + CrowdSec + Tailscale 리버스 프록시를 웹 화면 하나로 관리합니다.

**주요 기능**
- 서비스(서브도메인)별 공개/사설, Proxied/DNS only, mTLS, Authelia 정책·그룹, WAF — 엑셀·CSV 일괄 등록, 구성도
- 적용 = 생성 → 컨테이너 안에서 검증 → 백업 → 무중단 반영 → 상태 확인 → 실패 시 자동 롤백
- 기존 Caddyfile·Authelia 설정 가져오기, Cloudflare DNS·DDNS(IPv4·IPv6)·엣지 WAF 규칙, CrowdSec 판정 → Cloudflare 엣지 차단
- 기본 차단 + Coraza WAF(OWASP CRS), 대시보드, 감사·보안·시스템 로그
- 관리형 스택: Caddy·Authelia·CrowdSec이 없으면 옆 컨테이너로 설치
- 계정·역할·2단계 인증(TOTP), 재인증, 잠금, 접근 경로 제한
- 화면 언어 한국어 / English — 첫 접속에서 고르고 설정 탭에서 변경 (`GM_LANG`으로 미리 지정)

**0.1.1에서 고친 것**
- Docker 소켓 없이 `docker run -p`로만 띄우면 호스트에서의 첫 접속이 「허용되지 않은 경로」(403)로 막히던 문제 — 컨테이너의 기본 경로에서 게이트웨이를 알아냅니다

## English

One web UI for a Caddy + Authelia + Cloudflare + CrowdSec + Tailscale reverse proxy.

**Highlights**
- Per service (subdomain): public/private, Proxied/DNS only, mTLS, Authelia policy · groups, WAF — bulk import from Excel/CSV, topology diagram
- Apply = generate → validate inside the containers → back up → zero-downtime apply → health check → automatic rollback on failure
- Import an existing Caddyfile / Authelia config; Cloudflare DNS, DDNS (IPv4 · IPv6), edge WAF rules; CrowdSec decisions blocked at the Cloudflare edge
- Basic blocking + Coraza WAF (OWASP CRS), dashboard, audit · security · system logs
- Managed stacks: installs Caddy, Authelia and CrowdSec as sibling containers if you don't have them
- Accounts, roles, two-factor (TOTP), re-authentication, lockout, access-route restriction
- UI in Korean / English — chosen on the first visit, changed in Settings (preset with `GM_LANG`)

**Fixed in 0.1.1**
- Running the image with a plain `docker run -p` (no Docker socket) refused the host's first request with 403 — the gateway is now read from the container's default route

**Upgrading from 0.1.0:** `docker compose pull && docker compose up -d`
