네트워크 맵을 더한 릴리스입니다 — 길목이 아는 구성에 내 장비·연결·영역을 더해 집 네트워크 전체를 한 장에. · Adds a network map — your own devices, links and zones on top of what Gilmok already knows.

```bash
docker pull vitive/gilmok:0.1.23   # linux/amd64 · linux/arm64
```

**업데이트 · Upgrading:** `docker compose pull && docker compose up -d`

## 한국어

서비스 탭에 세 번째 보기 **「네트워크」**가 생겼습니다 (기존 「구성도」는 그대로).

- **자동으로 그려지는 부분**: 인터넷 → Cloudflare → 앞단 장비 → 이 서버 → Caddy → 서비스, 길목·Authelia·CrowdSec·Tailscale — 설정이 바뀌면 따라 바뀝니다
- **장비 추가**: 스위치·무선 AP·NAS·PC·노트북·휴대폰·VM·IoT·카메라·프린터·UPS 등 21종
- **연결 종류**: 유선 · 광 · 무선 · VPN · 가상 — 선 모양·색으로 구분, 이름표(예: 10GbE · VLAN 20)
- **영역**: LAN · DMZ · VLAN · 서브넷 · 무선망 상자(주소 범위·색). Shift+클릭으로 여러 장비를 묶고, 영역 이름표를 끌면 함께 이동
- **배치**: 끌어서 옮기면 저장, 「자동 배치」는 계층형(인터넷 → 서비스)으로 다시
- **상태 점검**: 장비마다 ping · TCP · HTTP — 길목이 30초마다 확인해 색으로 표시 (맵을 보고 있을 때만). Docker Desktop에서는 컨테이너 밖으로 ping이 안 나갈 수 있어 TCP·HTTP를 안내
- **보기**: 휠 확대 · 배경 끌기 · 맞춤 · 미니맵, 자동 칸 숨기기/되살리기
- **내보내기**: SVG · PNG 이미지, JSON 맵 백업 (가져오기 가능, 설정 백업에도 포함)
- 표시 전용이라 저장해도 「적용 대기」가 생기지 않습니다. 저장에는 「구성 변경」 권한이 필요하고, 링크 로컬·클라우드 메타데이터 주소는 점검 대상으로 받지 않습니다

## English

A third view on the Services tab: **Network** (the existing topology stays).

- **Drawn for you**: internet → Cloudflare → front devices → this host → Caddy → services, plus Gilmok, Authelia, CrowdSec and Tailscale — kept in step with your settings
- **Add devices**: switches, Wi-Fi APs, NAS, PCs, laptops, phones, VMs, IoT, cameras, printers, UPS … (21 kinds)
- **Link kinds**: wired · fiber · Wi-Fi · VPN · virtual, each with its own line style, plus labels (e.g. 10GbE · VLAN 20)
- **Zones**: LAN · DMZ · VLAN · subnet · wireless boxes with an address range and color. Shift+click to group devices; drag a zone's label to move them together
- **Layout**: drag to move (saved); "Auto layout" lays it out again in layers (internet → services)
- **Status checks**: ping · TCP · HTTP per device, run by Gilmok every 30 s while the map is open. On Docker Desktop ping may not leave the container — the form suggests TCP / HTTP
- **Viewing**: wheel zoom, drag the background, fit, minimap; hide / show the drawn boxes
- **Export**: SVG and PNG images, a JSON backup (importable, and part of the settings backup)
- Display only: saving never creates pending changes. Saving needs the "change configuration" permission; link-local and cloud metadata addresses are refused as check targets
