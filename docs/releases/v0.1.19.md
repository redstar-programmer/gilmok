구성도를 실제 경로대로 다듬은 릴리스입니다 — 바깥으로 나가는 API 호출이 공유기 등 앞단 장비를 거쳐 가고, CrowdSec이 서버 안에 그려지며, 흐름 애니메이션을 켜고 끌 수 있습니다. · The topology now draws real paths — outbound API calls go through the front devices, CrowdSec sits inside the host, and the flow animation can be switched on or off.

## 한국어

- 길목 → Cloudflare API 선이 서버에서 곧장 나가지 않고 앞단 장비(공유기 등)를 거쳐 나갑니다. 장비가 여러 개면 서버에 가까운 것부터 차례로
- CrowdSec을 서버 영역 안(Caddy 위)에 그립니다. 「접근 로그」는 Caddy에서 바로 위로, 「차단 목록」은 앞단 장비를 거쳐 Cloudflare로 — 실제로 보내는 쪽이 길목이라 라벨을 「차단 목록 (길목이 전송)」으로
- 운영체제의 「동작 줄이기」(애니메이션 효과 끔·원격 데스크톱)에서 흐르는 선이 실선으로 바뀌던 문제: 이제 점선은 남기고 움직임만 멈춥니다
- 구성도 조작에 「흐름: 자동 / 켜기 / 끄기」 — 운영체제 설정과 상관없이 켤 수 있고 브라우저별로 기억

## English

- The Gilmok → Cloudflare API line no longer leaves the host directly: it goes out through the front devices (router etc.), nearest the host first
- CrowdSec is drawn inside the host region (above Caddy). "Access log" goes straight up from Caddy; the "block list" leaves through the front devices to Cloudflare — labelled "Block list (sent by Gilmok)" since Gilmok is the sender
- With the OS "reduce motion" setting (animation effects off, remote desktop) flowing lines turned solid; now the dashes stay and only the movement stops
- New topology control "Flow: Auto / On / Off" — animate regardless of the OS setting, remembered per browser
